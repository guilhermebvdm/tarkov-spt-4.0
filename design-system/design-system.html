TRL Design System

The standard visual language for every Tarkov Red Line mod web editor. A neutral graphite base, tan/gold reserved for meaning (active, selected, primary), and red for the moments that matter.

Gold means, red speaks
The base is neutral graphite. Tan marks meaning — active, selected, primary, signatures. Red is the brand: laser, live dot, destructive — more than ~5% of the screen in either accent is wrong.
Hard edges
1px neutral hairlines, radius 0 everywhere; the tan frame (edge-accent) is reserved for accent chips. Military hardware has no rounded corners.
Elevation by light
Higher surfaces are lighter graphite, never just shadowed. Six neutral steps from ground-deep to popover — warmth comes from accents.
Tokens only
Product code consumes tier-2 semantic tokens (--trl-accent, --trl-bg-panel). Raw hex in an editor is a defect.

◇ ink-faint — 2.9–3.7 : 1 → decorative only (captions, separators, placeholders).

09 · Do's & Don'ts

Discipline

✓ Do — red as a moment
unsaved changes
One laser, one live dot, destructive actions. Red earns attention because it is rare.
✗ Don't — red as decoration
Red panels, red borders, red text everywhere…
#ff0000 never colors text or fills. Non-destructive actions never wear red.
✓ Do — hard edges, tan hairlines
Radius 0
--trl-radius is a system knob and it is 0. Borders are 1px translucent tan.
✗ Don't — rounded, soft, gray
pill tag
Rounded corners and neutral grays read as generic dashboards, not TRL.
✓ Do — tracking on display only
Squad status

Body text stays sentence case, Segoe UI, 13px — dense and readable.

Uppercase + letter-spacing is chrome. Body copy never shouts.
✗ Don't — uppercase paragraphs

Long tracked uppercase body text is exhausting to read and wastes space.

If it is more than ~4 words, it is body — drop the transform and tracking.
✓ Do — semantic tokens
color: var(--trl-fg-muted);
background: var(--trl-bg-raised);
border-color: var(--trl-edge);
Tier-2 tokens keep every editor retintable from one file.
✗ Don't — raw hex in editors
color: #9b9a96;      /* drift */
background: #222225;  /* drift */
border-color: #444;   /* not even ours */
Hardcoded hex forks the palette. It is a review defect.
10 · Consuming the DS

Consuming

Copy the design-system/ folder (or mount it) into your editor's static root, link the four files in order, and put class="trl-app" on your root element. Start new editors from templates/editor-starter.html.

<link rel="stylesheet" href="design-system/fonts/bender.css">   <!-- optional -->
<link rel="stylesheet" href="design-system/tokens.css">
<link rel="stylesheet" href="design-system/components.css">
<link rel="stylesheet" href="design-system/utilities.css">
<style>html, body { margin: 0; height: 100% }</style>  <!-- .trl-shell uses 100vh -->

<body class="trl-app"> … </body>
