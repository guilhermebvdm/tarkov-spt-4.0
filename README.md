# tarkov-spt-4.0

Repositório de mods para SPT 4.0 (Single Player Tarkov).

## Setup

```bash
git clone https://github.com/guilhermebvdm/tarkov-spt-4.0.git
cd tarkov-spt-4.0
bash .agents/hooks/install-hooks.sh
```

## Estrutura

- `.agents/` — contexto e workflows compartilhados (qualquer AI lê)
- `docs/` — documentação técnica
- `.claude/` — config do Claude Code

Ver [AGENTS.md](AGENTS.md) para detalhes.
