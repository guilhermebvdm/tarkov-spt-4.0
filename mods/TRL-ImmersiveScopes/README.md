# TRL-ImmersiveScopes

Mod de miras imersivas e efeito fisheye/óptica realística para Tarkov Red Line (SPT 4.0).

## Estrutura do Mod
- `Plugin.cs` — Ponto de entrada do plugin BepInEx e inicialização Harmony.
- `PROPRIEDADES.md` — Mapeamento de configurações do mod no menu F12.
- `assets/` — AssetBundles de shaders e lentes ópticas.
- `backlog/` — Especificações e itens de desenvolvimento.
- `docs/` — Documentação técnica.
- `memory/sessions.md` — Histórico de sessões e pendências.
