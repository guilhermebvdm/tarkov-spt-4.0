# TRL-ImmersiveOverlays

Mod de sobreposições visuais (overlays de óculos, viseiras e efeitos de tela) para Tarkov Red Line (SPT 4.0).

## Estrutura do Mod
- `modded/Client/` — Código-fonte C# do plugin (`Plugin.cs`, `OverlayController.cs`).
- `assets/` — Texturas, máscaras de viseira e AssetBundles visuais.
- `PROPRIEDADES.md` — Mapeamento das opções do menu F12.
- `backlog/` — Especificações funcionais e técnicas de tarefas.
- `docs/` — Documentação técnica.
- `memory/sessions.md` — Histórico de sessões e pendências do mod.
