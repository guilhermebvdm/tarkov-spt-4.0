# TRL-SpeakFromTarkov

Mod para Tarkov Red Line / SPT 4.0 habilitando falas e comandos de voz contextuais.

## Estrutura do Mod

- `PROPRIEDADES.md` — Mapeamento das opções do menu F12 (BepInEx ConfigurationManager).
- `ROADMAP.md` — Plano de desenvolvimento e roadmap de features do SpeakFromTarkov.
- `assets/` — Recursos de áudio e arquivos complementares.
- `backlog/` — Especificações funcionais e técnicas de tarefas.
- [`docs/`](./docs/README.md) — Documentação técnica modular (arquitetura, DSP, rede, bots, UI).
- `memory/sessions.md` — Histórico de sessões e pendências do mod.
